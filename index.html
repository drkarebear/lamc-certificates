Independent faculty guide to English OER

Too many OERs?
Start with the strongest matches.

A practical guide for California Community College English faculty: compare course-specific OER alignment, see what each resource does well, note what it may still need, and add faculty recommendations and teaching notes.

The idea is simple.

The ASCCC OERI already does the essential work of identifying and collecting English OER. This project adds a practical comparison layer: Which resources look strongest for a specific CCC course, what role might each one play, and what do faculty say after using them?

Each course page separates editorial alignment from faculty recommendations. Alignment scores are an independent review of how well a resource appears to match that course's statewide requirements; faculty reviews reflect real teaching experience.

Choose Your Course

Start with the course you teach. Each guide uses its own course-specific criteria, so a resource can be an excellent fit for one course and only a supplement for another.

Independent, not official

Scores are an independent course-alignment review, not an ASCCC, OERI, or Chancellor's Office rating.

Different courses, different roles

The same resource may be a strong primary text in one course and a targeted supplement in another.

Sometimes a combination works best

The guides highlight complementary strengths so faculty can build a better-fit set of materials when one text does not do everything.

Built beside OERI, not instead of it.

ASCCC OERI maintains the comprehensive, discipline-curated collection of English OER. This independent project adds a practical comparison layer to help faculty decide what to investigate first.
